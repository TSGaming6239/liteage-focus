# Liteage Focus 🎯
> **Find your solution. Focus on your goals.**

Liteage Focus is a student-first digital directory that helps school and competitive examination students find verified, free solutions for everyday academic and productivity bottlenecks.

Built for **Youth Ideathon India Challenge 9 (YIIC 9) — Week 2**.

---

## 🌟 The Problem We Solve
Students struggle to find suitable digital solutions for their academic and productivity problems. Useful resources are scattered across the internet, many tools do not suit their devices or routines, and important features are often locked behind paid plans.

### Core Philosophy:
1. **Problem-First:** Search and browse by what you are struggling with, not software brand names.
2. **Free-First:** Prioritizing genuine 100% free or generous student tiers without forced subscriptions.
3. **One Researched Recommendation:** One clear primary solution to eliminate decision fatigue, plus 2 transparent alternatives.
4. **Radical Transparency:** Clear disclosure of supported devices, free-tier limits, caveats, and step-by-step setup guides.
5. **Zero AI Fluff:** No synthetic chatbots or automated hallucinations; every recommendation is hand-verified.

---

## 📱 Three Core Screens
1. **Screen 1 — Home (Discovery & Search):**
   - Interactive search bar filtering problems in real-time.
   - Category filtering (Distractions, Time Management, Notes & Material, Revision & Memory, Exam Preparation).
   - Problem cards highlighting symptoms, target devices, and recommended tools.
2. **Screen 2 — Problem Page:**
   - Problem context, field interview struggles, and target audience.
   - Primary Recommended Solution highlight card with compatibility badges.
   - "Why We Recommend It" vs "Important Limitations" side-by-side.
   - Curated alternative options.
3. **Screen 3 — Solution Details & Implementation Guide:**
   - Deep-dive into verified official tool links, licensing, and pricing breakdown.
   - Device compatibility matrix.
   - Step-by-step 4-stage student implementation guide with practical tips.
   - Comparison with alternative tools.

## 🛠️ Tech Stack
- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS (Clean slate/blue student palette)
- **Icons:** Lucide React
- **Architecture:** Hash-based client routing, local state persistence for saved items ("My Focus"), fully responsive design (desktop, tablet, mobile).

---

## 🚀 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/TSGaming6239/liteage-focus.git
   cd liteage-focus
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your web browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
